# 操作手册（请按顺序做，不要跳步）

> 这件事**不需要你懂技术**。你只需要重复做「上传两个文件 → 粘贴一句话 → 保存一段文字」。
> 全程大约 30 轮，每轮 5 分钟。中途可以停，明天接着做也没问题。

---

## 一、这件事到底是什么（30 秒看完）

我们有一个网站，上面有 83 个「实验方法」和 1 万多个「实验步骤说明」。
有些步骤说明被错误地挂到了不相关的方法下面，需要有人逐条判断对错。

这个判断工作被切成了 **30 份**，每份 500 条。你要做的就是：
**把每一份交给 Claude，让它给出判断，然后把它给的结果保存下来。**

全部做完后，把这些结果文件交回来，我们这边会自动核对。

---

## 二、你会收到什么

一个压缩包，解压后是这样三个文件夹：

```
📁 2_上传给Claude
     READ_ME_FIRST.md          ← 每轮都要传这个
     part_01.jsonl             ← 第 1 份数据
     part_02.jsonl             ← 第 2 份数据
     ...（一直到 part_30.jsonl）
     gold_questions.jsonl      ← 只在"考试"那一步用一次（63 道题）

📄 3_提示词.txt                 ← 每轮复制里面的文字

📄 1_先看这个_操作手册.md        ← 你正在看的这个文件
```

**解压方法**：右键点压缩包 → 选「全部解压缩」→ 点「确定」。
解压后会多出一个文件夹，进去就能看到上面这些内容。

⚠️ **不要改名、不要移动文件**。Claude 靠文件名识别。

---

## 三、第 0 步：先"考试"，看 Claude 靠不靠谱

这一步只做一次，但**非常重要**——先确认 Claude 判得准，再让它干 1 万多条。
如果它考试都不及格，后面做的都是白费。

### 重要：这次考试是"闭卷"

你上传的文件里**没有答案**，Claude 不可能偷看。它判完之后把结果交回来，
**由我们这边算分数**。

所以你不能指望 Claude 当场告诉你"我考了 88 分"——它算不出来，也不需要算。

### 操作

1. 打开 Claude（网页版就行）
2. **新建一个对话**
3. 点输入框下面的「📎」图标，上传这两个文件：
   - `READ_ME_FIRST.md`
   - `gold_questions.jsonl`
4. 打开 `3_提示词.txt`，找到「【第 0 步 · 考试用】」那一段，
   把**那一段整段**复制，粘贴到 Claude 的输入框，点发送
5. 等它回答（大约 1 分钟）

### 你会看到

Claude 会输出 **63 行 JSON**，每行一条判定，最后补一句它对整体把握程度的自评。

### 你要做的

把这段输出**保存成文件**，命名 `考试结果.txt`，然后发给我。

保存方法和后面正式批次一样（看第五节）：复制 → 记事本 → 另存为 → **编码选 UTF-8**。

### 我拿到之后

我会用留在我这边的一份答案（**没有放进压缩包**）逐条比对，告你三个数：

- 总体准确率
- 三种判定各自判对多少（on_topic / wrong / tangential）
- 具体哪几条判错了

| 我给出的结果 | 你要做什么 |
|---|---|
| **≥ 85%** | ✅ 继续做第四步，开始正式标注 |
| **< 85%** | ❌ 先停下，我们讨论要不要换个模型 |
| tangential 那 7 条基本全错 | ⚠️ 也能做，但我会告诉你哪些结果需要人工复核 |

> 为什么单独看 tangential：这一档最难判（"沾边但不核心"），
> 我们之前实测过，连两个不同的模型自己都经常在这档上打架。
> 所以它错得多不代表整体不能用，但要提前知道。

## 四、第 1 步到第 30 步：正式干活

**每一轮都是完全一样的 5 个动作**，只是换数据文件。做过一轮你就熟了。

### 动作 1：新建对话

⚠️ **每做一份就新建一个对话**，不要在同一个对话里连着做。

原因：Claude 的记忆容量有限，同一个对话里塞太多东西，后面的判断会变差。

点 Claude 左上角/侧边栏的「New chat」或「新对话」。

### 动作 2：上传两个文件

点「📎」，上传：

- `READ_ME_FIRST.md`（**每轮都要传，别嫌麻烦**）
- `part_01.jsonl`（第二轮就换成 `part_02.jsonl`，以此类推）

### 动作 3：粘贴提示词

打开 `3_提示词.txt`，找到「【第 1~30 步 · 正式用】」那一段，
复制，粘贴，**把里面的 `XXX` 改成你这次传的编号**（比如传的是 part_07，就写 7），
然后发送。

> 举例：`这是第 7 份（共 30 份），文件名 part_07.jsonl。`

### 动作 4：等 Claude 输出

它会输出一大段 JSON，每行一条，一共 500 行左右。**等它完全输出完**（不要中途打断）。

### 动作 5：保存结果（关键，别漏）

Claude 的输出要保存成一个文件，我们才能用。

**方法 A（推荐，如果 Claude 能下载文件）**
如果 Claude 提供了「下载」按钮或生成的文件，直接下载，改名为：
`part_01_out.txt`（对应你这次做的是 part_01）

**方法 B（Claude 只显示文字）**

1. 在 Claude 回答的右上角找「复制」按钮（两个方块重叠的图标），点一下
2. 打开电脑上的「记事本」：按键盘 `Win 键`，输入"记事本"，回车
3. 在记事本里按 `Ctrl + V` 粘贴
4. 点「文件」→「另存为」
5. 文件名填 `part_01_out.txt`
6. **编码选「UTF-8」**（这一项很重要，选错中文会乱码）
7. 存到桌面上新建的「Claude结果」文件夹里

### 做完一份的标志

桌面的「Claude结果」文件夹里，多了一个 `part_01_out.txt`，
而且**用记事本打开能看到几百行 JSON**（以 `{` 开头）。

看到这个，就说明第 1 份做完了，接着做第 2 份。

## 五、做完之后怎么交回来

30 份全部做完后：

1. 打开桌上的「Claude结果」文件夹
2. 确认里面有 **30 个文件**，名字是 `part_01_out.txt` 到 `part_30_out.txt`
3. 全选这 30 个文件，右键 → 压缩成 zip
4. 把这个 zip 发回给我

**中途也可以交**：做多少交多少，我们这边能分批核对。
比如做了 5 份想先看看效果，把 5 个文件打包发给我就行。

## 六、遇到这些情况怎么办

| 情况 | 怎么办 |
|---|---|
| Claude 说文件太大 / 读不了 | 截图或复制它的原话发给我 |
| Claude 输出的东西被截断（最后一行不完整） | 告诉它「请继续输出剩下的部分」，然后接着存 |
| Claude 没按格式输出（说了很多废话） | 提醒它「只要 JSON，不要解释文字」 |
| 某一份做了一半卡住了 | 重新新建对话，把这一份重做一遍 |
| 不确定做没做完 | 数结果文件的行数，应该在 500 行左右 |
| 电脑重启 / 隔天接着做 | 没问题，看「Claude结果」文件夹里已经有几个文件，从下一个编号继续 |

## 七、三个最容易出错的地方（重点看）

### ❌ 错误 1：把 30 份塞进一个对话里做

**后果**：Claude 越做越糊涂，后面几份质量断崖下跌。

**正确做法**：一份一个新对话。

### ❌ 错误 2：忘了每轮都上传 READ_ME_FIRST.md

**后果**：Claude 不知道规则，会瞎判，而且你不知道哪份是瞎判的。

**正确做法**：每次新建对话后，先传 READ_ME_FIRST.md 再传数据。

### ❌ 错误 3：以为考试要 Claude 自己报分数

**后果**：你会一直等一个它给不出的数字。

**正确做法**：它给 63 行 JSON 就说明做完了，保存下来发给我，分数由我来算。

### ❌ 错误 4：保存结果时编码选错

**后果**：中文变成乱码，整份作废。

**正确做法**：记事本另存为时，编码下拉框一定选 **UTF-8**。

## 八、你现在就能开始做的三件事

1. 解压压缩包
2. 打开 Claude，按「第 0 步」做一次考试
3. 把考试成绩告诉我

考试通过以后再往下做。**不要跳过考试**——万一 Claude 判不准，做 30 份就白干了。
