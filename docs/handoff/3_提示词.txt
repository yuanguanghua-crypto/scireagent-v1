这是第 5 份（共 30 份），文件名 part_05.jsonl。

请按 READ_ME_FIRST.md 的规则，逐条判定这 500 条记录，输出 JSONL。

输出要求（每一条都必须满足）：

1. 严格保持输入顺序。输入 500 条，就输出 500 行，不许合并、去重、跳过任何一条。
2. 每行字段：task / method_id / protocol_id / verdict / criteria_hit / confidence / reason
3. criteria_hit 不能为空，必须写四者之一：
   exclude#数字、must#数字、universal#数字、definition

5. 拿不准的，判 wrong 并把 confidence 设成 low。
   不要把 tangential 当保险档——它只用于"确实有这个方法的一步、但不是主体"。
6. 只输出 JSON 行，不要任何解释文字、不要 markdown 代码块围栏、不要编号。

如果输出太长被截断了，我会让你"继续"，你就从断掉的地方接着输出。
