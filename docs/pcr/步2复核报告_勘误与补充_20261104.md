## 二、勘误二：「字节」标签用错 —— 那是**字符数**

原报告写「正文字节 615,037 / 3,092,887」，**标签错**：

- Postgres 侧我取的是 `length(text)` —— 返回**字符数**，不是字节；
- Python 侧我取的是 `len(str)` —— 也是**字符数**（码点数）。

两边口径一致，所以"相等"这个结论本身没错，但**它不是字节核对**。你指出得准。

### 2.1 真字节对账（本次补做，双向独立）

DB 用 `octet_length()`，Python 用 `len(s.encode('utf-8'))`，**分三段（objective / title / body）逐项比**：

| **SDS**（144） | objective | 113,838 | 113,838 | ✅ |
| | title | 105,864 | 105,864 | ✅ |
| | body | 398,032 | 398,032 | ✅ |

⇒ **真字节数与字符数不同**（SDS 617,734 vs 615,037；PCR 3,114,132 vs 3,092,887），差额来自非 ASCII 字符。
